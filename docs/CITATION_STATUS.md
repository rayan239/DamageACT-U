# Citation metadata status

The research implementation and frozen experimental evidence were completed before manuscript authorship/affiliations were finalized.

Therefore this repository intentionally does **not** publish final citation metadata on the current `master` branch. A previous placeholder `CITATION.cff` existed in the frozen `paper-v1.0.0` snapshot; its placeholder author/repository fields are **not valid bibliographic metadata and must not be used for citation**.

When the manuscript author list, affiliations and citation title are finalized:

1. create a valid `CITATION.cff` on `master`;
2. include the repository URL and the appropriate software version;
3. add ORCIDs only where actually known;
4. create a later documentation/release tag if a citable software snapshot is needed;
5. do not move or rewrite the already tested `paper-v1.0.0` tag.

Until then, cite neither guessed author names nor placeholder affiliations.
